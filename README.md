** Equipment Rental System, this project has been assigned to me as part of my Software Developmet Lifecyle Managment. The goal of this system is to enable an equipment rental company to rent out equipment to customers. This system will demonstrate a workflow of customers and staff, from browing catalogues, to selecting an equipment, submitting a booking, staff reviewing and approving the booking, booking moving from Pending state to, Approved or Rejcted states, Ready to Pickup state and Picked up state.  **

**This apps **contain** the following features:**

* Register
* Login
* Logout
* Create booking
* Browse Catalogue
* View booking details 
* View equipment detail
* Set booking statuses
* Set equipment statuses
* Add and remove equipment 
* Create staff account


Features 
Customer ability to submit bookings for equipment. 
Staff ability to approve or reject booking of equipment. 

Tech Stack 
React
Tailwind
Node / Express
MondoDB Atlas
JWT 
pm2
nginx 
Github Actions


Limitations
The server time zone (UTC) for the day rule; cors() open to all origins; npm audit vulnerabilities from CRA; the JWT in localStorage; pm2 processes set up by hand; the small EC2 disk; malformed IDs returning 500; the backlog items (sidebar, My Bookings, manager equipment management)
